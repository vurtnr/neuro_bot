Python packages use ament_python layout with snake_case modules/functions, PascalCase classes, and main() ROS entrypoints. Tests live under each package's test/ directory and use pytest or unittest. Rust packages use ament_cargo + r2r, with async tokio-based main.rs files and logic split into modules/. Keep package names snake_case. Treat robot_interfaces as the source of truth for ROS contracts, and rebuild it first when msg/srv files change. Preserve existing launch ordering and hardware assumptions unless intentionally changing deployment behavior.
