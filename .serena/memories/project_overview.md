NeuroBot is a ROS 2 robot workspace under /Users/jiaoyumin/workspace/robot_dashboard/neuro_bot. It uses a mixed Rust + Python architecture. Core packages: robot_interfaces (ROS msg/srv contracts), brain_core (Rust coordinator), iot_controller (Rust BLE/servo/network control), face_bridge (Rust serial bridge), vision_engine (Python QR/snapshot/gating), audio_engine (Python ASR/TTS and echo guard), llm_engine (Python LLM node), inspection_bridge (Python HTTP/SSE bridge), neuro_bot_bringup (launch package). Top-level scripts include start.sh, run.sh, vision_system.launch.py, ble_debug.py, and test_audio.py.
